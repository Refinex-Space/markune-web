未带目录前缀的界面文件位于 `components/workspace/`。示例均为说明性文本；Git 示例只包含检查命令，没有执行对用户仓库的写入或同步。

后续优先补充：附件保存策略（相关改动正式发布后）、外观与快捷键专项、实际故障排查案例。对于终端、视图等其他入口，应先单独核对完整操作与发布状态，再扩展手册。

## 页面与路由

- 索引使用三类指南、入门推荐、标题与摘要关键词搜索、匹配数量、无结果提示和重置操作。筛选与搜索组合生效。
- 首页推荐同步使用新内容与卡片，保留其他首页区域及全站导航结构。
- 8 个有意义的新 slug 用于索引和内部链接；6 个旧模板 slug 通过显式映射继续渲染相应指南，保证静态站点旧地址可访问。
- 当 `NEXT_PUBLIC_SITE_URL` 已配置时，详情页 canonical 指向新地址。没有引入服务器重定向或新增部署要求。
- 文档按三个内容文件维护，使用明确的段落、步骤、列表、表格、示例、插图和提示结构。渲染器不执行原始 HTML 或用户脚本；复制示例保持原始换行与空格。

## 阅读设计

正文与桌面右侧目录分栏；手机目录收起并在滚动时保留入口。当前章节自动高亮，阅读进度跟随正文。标题按中文标点合理换行，正文不使用滚动显隐动画，博客页面关闭原有底部模糊遮罩。

代码支持横向滚动、键盘聚焦、复制成功和失败反馈；表格保留表头、标题与局部滚动。图片可以在原生对话框中放大，支持关闭按钮和 Escape，配套打印样式隐藏交互控件。

Inbox 插图复用仓库中已有的实际界面截图，仅用于展示与当前实现吻合的“流转”菜单；示例工作区名称并不代表用户必须创建该名称。没有使用虚构功能配图或 AI 生成的应用界面。
